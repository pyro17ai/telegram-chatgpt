# Подключение в ChatGPT

Основной путь для сервера: пройдите Telegram-вход на его главной странице и скачайте `Telegram.zip`. Он содержит `plugin.json`, `mcp.json` с адресом вашей установки и оба навыка. Секретов в ZIP нет. Передайте архив Plugin Creator и попросите создать приватный плагин; затем установите и подключите его. Если загрузка плагинов доступна в рабочем пространстве, архив можно добавить через Admin console → workspace → Plugins → Add → Upload plugin.

Запасной путь: Plugins → + → Add custom MCP server, адрес MCP из страницы вашей установки, OAuth, затем Create as a plugin. Бесплатный адрес `sslip.io` подходит для этого сценария; покупать домен не требуется. Этот путь подключает MCP; навыки добавьте через Plugin Creator. MCP также отдаёт исходные навыки через `read_skill_file` и сообщает об этом при инициализации. Для работы требуется разрешить инструмент исполнения: он помечен как способный изменять данные, потому что выполняет произвольный код SDK.

Откройте персональную ссылку установки в том браузере, где используете ChatGPT. Она сохранит вход владельца, и на странице OAuth останется подтвердить доступ. Если cookie истекла или вы открыли другой браузер, войдите ключом владельца из приватного `.env` (`SETUP_TOKEN`). Пароль Telegram здесь не требуется: Telegram-сессия уже создана на этапе настройки. Авторизация использует Dynamic Client Registration, PKCE S256 и обновляемые токены. Встроенно разрешены официальные callback-адреса ChatGPT. Для другого доверенного MCP-клиента задайте точные адреса в `OAUTH_EXTRA_REDIRECT_URIS` через запятую, затем перезапустите сервер. Не добавляйте маски доменов.

На Sites используйте приватный плагин, который создала сама платформа. Не создавайте второй плагин поверх этого же сайта. Telegram ZIP на Sites для этого пути не требуется: агент добавляет навыки в канонический плагин.

Доступность custom MCP зависит от тарифа и настроек рабочего пространства. На 19 октября 2026 официальная справка описывает полный custom MCP для Business/Enterprise/Edu, а для Pro указывает ограничение read/fetch. Инструмент `execute_typescript` не следует выдавать за read-only ради обхода этого ограничения. Инструкция Sites описывает Sites-hosted plugins на планах с доступом к Sites. Перед установкой проверьте доступные действия в вашем аккаунте.
