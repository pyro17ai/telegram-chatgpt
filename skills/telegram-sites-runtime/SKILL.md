# Исполнение Telegram SDK через MCP

Сначала прочитай telegram-account-sdk. Публичная копия исходного навыка использует переносимые пути. Этот дополнительный навык задаёт запуск на сервере или ChatGPT Sites. Если файлов навыков нет в файловой системе ChatGPT, получи их через read_skill_file: telegram-account-sdk/SKILL.md и telegram-sites-runtime/SKILL.md. Этот инструмент возвращает точный текст и SHA-256 файла; отсутствие локального пути не блокирует работу.

Вместо локального Bun отправляй весь TypeScript в инструмент execute_typescript плагина Telegram. Поле code содержит исходный код, request_id содержит новый уникальный идентификатор запуска. При неизвестном результате повторяй запрос с тем же request_id: сервер не исполнит его повторно. Для исправленного кода используй новый request_id.

Среда поддерживает JavaScript и TypeScript через QuickJS. Bash, Bun и произвольные исполняемые файлы ОС здесь не запускаются. Не вызывай локальный терминал ChatGPT для управления этим Telegram: аккаунт находится на сервере плагина.

Глобальная функция withTelegram предоставляет tg и me. Импорт withTelegram из абсолютного пути исходного scripts/client.ts также поддерживается. Подключён mtcute 0.32.2. tg предоставляет методы SDK, включая tg.call; отдельной команды MCP на каждый метод нет. Асинхронные итераторы SDK работают с for await. Метод SDK может вернуть объект с геттерами и методами; выбирай нужные поля в вывод самостоятельно.

```typescript
await withTelegram(async (tg, me) => {
  console.log(JSON.stringify({userId: me.id, isBot: me.isBot}));
});
```

Проверку сигнатур выполняй по документации mtcute и исходным ресурсам навыка. Можно вызвать sdk_reference с именем метода, чтобы прочитать точную декларацию установленной версии. Поддерживаются импорты @mtcute/core и long. Другие npm-пакеты автоматически не устанавливаются. Callback-функции как параметры вызовов SDK пока не переносятся через границу интерпретатора; обычные функции внутри программы и callback withTelegram поддерживаются.

Результат возвращает stdout и признак ok; ошибки не означают, что предшествующая запись не состоялась. Каждый запуск ограничен 45 секундами и 240 КБ вывода. Делай большие выборки несколькими запусками. Сохраняй промежуточные данные через await files.write(path, text), читай через await files.read(path), получай имена через await files.list(). Файлы сохраняются в зашифрованном виде между запусками. Доступен fetch для HTTPS-запросов. Правила разрешений на отправку из исходного навыка сохраняются.

## Папки и новости

Папки Telegram получай через tg.call({ _: 'messages.getDialogFilters' }). Учитывай включённые и закреплённые диалоги, исключения и флаги папки; не считай список includePeers полным для папок с автоматическими правилами. Перед незнакомой операцией проверь sdk_reference. Для новостей читай только каналы в папках, названных пользователем. По умолчанию используй последние 24 часа и явно указывай интервал; если данных не хватает, объясни расширение периода. Объединяй сообщения об одном событии, ранжируй по влиянию на жителей России и приводи ссылки на исходные сообщения. Не подменяй чтение Telegram веб-поиском.

## Первое подключение

Если Telegram ещё не подключён, предложи владельцу открыть главную страницу сервера и пройти вход в веб-форме. Не проси API Hash, код Telegram или пароль 2FA в чате. После входа проверь getMe через execute_typescript. Не запускай локальные scripts/client.ts или login-qr.ts: в этой установке они служат справочными примерами.
