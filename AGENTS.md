# Установка по поручению владельца

Если пользователь передал этот репозиторий и доступ к серверу, доведи установку до работающей страницы входа. Следуй [docs/deploy-server.md](docs/deploy-server.md). Не проси купить домен: основной сценарий создаёт бесплатный адрес по публичному IPv4 сервера. Установи Git и Docker с Compose, если их нет, через официальный способ для обнаруженной ОС. Node.js на сервере не требуется.

Запускай установщик именно на целевом сервере. Сначала проверь публичный IP и свободные TCP-порты 80/443; не останавливай посторонние сервисы. Если у сервера уже есть reverse proxy, добавь маршрутизацию для новой установки без нарушения существующих сайтов. Существующий `.env` и Docker volumes сохраняй при обновлении. Не подменяй ключ шифрования ради повторного запуска.

После запуска проверь HTTPS с доверенным сертификатом извне сервера и OAuth metadata. Передай владельцу персональную ссылку из вывода установщика в приватном чате. Не помещай её в Git, публичные журналы или скриншоты. Не запрашивай Telegram API Hash, код или пароль 2FA в чате: владелец вводит их в веб-форме. Для ChatGPT нужен плагин с обоими навыками; следуй [docs/chatgpt.md](docs/chatgpt.md). Деплой на Sites описан отдельно в [docs/deploy-sites.md](docs/deploy-sites.md).
